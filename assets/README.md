# BGM Track Ke Baare Mein

Isi folder mein `default_bgm.mp3` naam ki file daal do — yahi background music
har video mein use hogi jab user BGM "ON" karega.

## Free royalty-free music kahan se lein:
- https://pixabay.com/music/ (no attribution chahiye)
- https://www.bensound.com/ (free with attribution)
- https://incompetech.com/music/royalty-free/ (Kevin MacLeod — attribution chahiye)

## Tips:
- Soft/ambient instrumental track choose karo — voice ke saath clash nahi karna chahiye
- 2-4 minute ka loop-friendly track best hai (bot automatically loop kar dega agar video lambi hai)
- File ka naam exactly `default_bgm.mp3` hona chahiye

Path jahan rakhna hai: `assets/default_bgm.mp3`
